# 照片水印工具

一个基于Python实现的简单易用的照片水印本地应用，支持批量图片导入、处理、添加水印和导出功能。

## 技术栈
- **编程语言**: Python 3.7+
- **GUI框架**: Tkinter (Python标准库)
- **图像处理库**: Pillow (PIL)
- **配置管理**: JSON文件存储

## 功能特性

### 1. 文件处理

#### 1.1 导入图片
- **单张导入**：通过文件对话框或拖拽功能导入
- **批量导入**：支持一次性选择多张图片
- **文件夹导入**：支持导入整个文件夹中的所有图片
- **图片列表**：界面上显示已导入图片的缩略图和文件名列表

#### 1.2 支持格式
- **输入格式**：JPEG (.jpg, .jpeg)、PNG (.png)、BMP (.bmp)、TIFF (.tif, .tiff)，PNG支持透明通道
- **输出格式**：用户可选择 JPEG (.jpg) 或 PNG (.png)

#### 1.3 导出图片
- **输出文件夹**：用户可指定，默认禁止导出到原文件夹
- **命名规则**：支持保留原文件名、添加自定义前缀或后缀
- **质量调节**：JPEG格式支持0-100的质量调节
- **尺寸调整**：支持按百分比缩放图片

#### 1.4 技术实现
- **FileHandler类**：负责文件选择、批量导入和文件名处理
- **ImageProcessor类**：负责图片加载、保存和缩放等核心功能
- **ImageUtils类**：提供辅助功能如创建缩略图、格式转换等

## 后续功能预留接口

- 水印类型：支持文字水印、图片水印等
- 水印布局与样式：支持调整水印位置、大小、透明度、旋转等
- 配置管理：支持保存和加载水印配置
- 水印模板：支持创建和应用水印模板

## 安装说明

1. 确保已安装 Python 3.7 或更高版本

2. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

1. 运行应用
   ```bash
   python app.py
   ```

2. **导入图片**：
   - 拖拽图片或文件夹到应用的拖放区域
   - 点击"导入图片"按钮选择单个或多个图片
   - 点击"导入文件夹"按钮选择包含图片的文件夹

3. **设置输出参数**：
   - 选择输出文件夹
   - 选择输出格式（JPEG 或 PNG）
   - 设置文件名前缀和后缀
   - 调整 JPEG 质量（如果选择 JPEG 格式）
   - 调整图片缩放比例

4. **导出图片**：点击"导出图片"按钮开始导出
