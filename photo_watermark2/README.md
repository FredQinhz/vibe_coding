# 图片水印工具

一个基于Python的图片水印应用程序，支持多种图片格式的导入、处理和导出，并提供丰富的水印添加功能。

## 功能特性

### 文件处理
- 支持单张和批量导入图片
- 支持JPEG、PNG、BMP、TIFF等多种图片格式
- 支持PNG透明通道
- 可选择导出为JPEG或PNG格式
- 支持自定义文件命名规则（前缀、后缀）

### 水印功能
- 文本水印：支持自定义文本内容、字体、颜色、透明度等
- 多种预设位置：九宫格布局选择
- 手动拖拽水印位置
- 实时预览水印效果

### 配置管理
- 水印模板保存和加载
- 自动加载上次关闭时的设置

## 安装说明

1. 确保已安装Python 3.8或更高版本
2. 安装依赖包：
   ```
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```
   python main.py
   ```

## 使用指南

1. 通过拖拽或文件选择器导入图片
2. 在文本水印区域输入水印内容
3. 调整水印的字体、颜色、透明度等参数
4. 选择水印位置或手动拖拽到理想位置
5. 选择输出文件夹和命名规则
6. 点击导出按钮完成处理

## 开发说明

本项目基于Python和PyQt5开发，使用Pillow库处理图片。项目采用模块化设计，便于维护和扩展。
