# 照片水印应用需求规格说明

## 项目概述
开发一款Windows平台的本地照片水印应用，基于Python实现，支持多种图片格式的导入、处理和导出，并提供丰富的水印添加功能。

## 技术栈选择
- **编程语言**: Python 3.7+ （确保良好的跨平台兼容性和开发效率）
- **GUI框架**: Tkinter （Python标准库，无需额外安装，适合轻量级桌面应用）
- **图像处理库**: Pillow (PIL) （Python图像处理的标准库，支持各种格式的图片处理）
- **配置管理**: JSON文件存储（轻量级、易于实现和解析）

## 1. 文件处理

### 1.1 导入图片
- **单张导入**：通过Tkinter的文件对话框(`filedialog.askopenfilename`)实现，或通过拖拽功能实现
- **批量导入**：
  - 多选导入：通过Tkinter的文件对话框(`filedialog.askopenfilenames`)支持一次性选择多张图片
  - 文件夹导入：通过Tkinter的文件夹对话框(`filedialog.askdirectory`)支持导入整个文件夹下的所有支持格式图片
- **拖拽功能**：利用Tkinter的事件绑定机制实现文件拖放，通过`<<Drop>>`和`<<DragOver>>`事件处理
- **图片列表显示**：
  - 界面上使用Tkinter的`Canvas`或`Frame`与`Label`组合实现缩略图网格布局
  - 每个缩略图项包含图片预览和文件名标签
  - 支持图片项的选择和移除功能

### 1.2 支持格式
- **输入格式**：
  - 必须支持：JPEG (.jpg, .jpeg)、PNG (.png)
  - 强烈建议支持：BMP (.bmp)、TIFF (.tif, .tiff)
  - PNG格式处理：通过Pillow库的`Image.open()`和`Image.save()`方法确保透明通道的正确处理和保存
- **输出格式**：
  - 用户可选择：JPEG (.jpg) 或 PNG (.png)
  - 实现方式：通过Pillow库的`image.save()`方法，根据用户选择设置不同的格式参数

### 1.3 导出图片
- **输出文件夹选择**：使用Tkinter的`filedialog.askdirectory`实现，通过路径比较默认禁止导出到原图片所在文件夹
- **文件命名规则**：
  - 保留原文件名：直接使用原始文件名
  - 添加自定义前缀：在原文件名前添加用户指定的前缀字符串
  - 添加自定义后缀：在原文件名（不含扩展名）后添加用户指定的后缀字符串
  - 实现方式：通过Python的`os.path`模块解析和构建文件路径
- **JPEG质量调节**：
  - 提供0-100的滑块控制
  - 实现方式：在Pillow的`image.save()`方法中设置`quality`参数
- **图片尺寸调整**：
  - 支持按百分比缩放
  - 实现方式：通过Pillow的`Image.resize()`方法，使用高质量的缩放算法（如`Image.Resampling.LANCZOS`）

### 1.4 技术实现类设计
- **FileHandler类**：负责文件选择、批量导入、文件名处理等功能
- **ImageProcessor类**：负责图片的加载、保存、缩放等核心图像处理功能
- **ImageUtils类**：提供辅助功能，如创建缩略图、图像格式转换等
- **UI组件**：包括文件拖放区域、图片缩略图组件等

## 2. 水印类型

### 2.1 文本水印
- **内容输入**：通过Tkinter的`Entry`或`Text`组件实现用户文本输入
- **字体设置**：
  - 字体选择：通过Tkinter的`OptionMenu`组件显示系统已安装字体列表
  - 字号选择：通过`Spinbox`或滑块组件实现字号调节
  - 字体样式：通过`Checkbutton`组件实现粗体、斜体的开关控制
  - 实现方式：利用Pillow的`ImageDraw`模块的`text()`方法，设置`font`参数
- **颜色选择**：
  - 提供调色板组件（如颜色选择器对话框）
  - 实现方式：通过Tkinter的`colorchooser`模块或自定义颜色选择组件
- **透明度调节**：
  - 提供0-100%的滑块控制
  - 实现方式：通过RGBA颜色模式设置alpha通道值
- **样式效果**：
  - 阴影效果：通过在不同位置绘制多次文本实现
  - 描边效果：通过先绘制文本的描边轮廓，再绘制内部文本实现
  - 实现方式：使用Pillow的`ImageDraw`模块的相关方法

### 2.2 图片水印
- **图片选择**：通过Tkinter的文件对话框选择本地图片文件
- **透明通道支持**：确保使用Pillow的`Image.open()`方法正确加载和处理带透明通道的PNG图片
- **缩放功能**：
  - 按比例缩放：通过滑块控制缩放百分比
  - 自由调整：提供宽高输入框，支持锁定/解锁宽高比例
  - 实现方式：使用Pillow的`Image.resize()`方法
- **透明度调节**：
  - 提供0-100%的滑块控制
  - 实现方式：使用Pillow的`Image.putalpha()`或`Image.blend()`方法

### 2.3 技术实现类设计
- **WatermarkBase类**：水印基类，定义通用接口
- **TextWatermark类**：继承WatermarkBase，实现文本水印功能
- **ImageWatermark类**：继承WatermarkBase，实现图片水印功能

## 3. 水印布局与样式

### 3.1 实时预览
- **预览窗口**：使用Tkinter的`Canvas`组件作为主预览区域
- **实时更新**：
  - 当用户调整任何水印参数时，立即重新渲染预览图
  - 实现方式：采用事件绑定机制，当控件值变化时触发预览更新函数
- **图片切换**：
  - 用户点击图片列表中的缩略图时，切换主预览窗口显示的图片
  - 实现方式：通过变量绑定和回调函数实现

### 3.2 位置控制
- **预设位置**：
  - 提供九宫格布局按钮组（左上、右上、左下、右下、上中、下中、左中、右中、中心）
  - 实现方式：点击按钮时计算并设置相应的水印位置坐标
- **手动拖拽**：
  - 用户可以在预览图上直接拖拽水印到任意位置
  - 实现方式：通过Tkinter的`Canvas`组件的鼠标事件（`<<ButtonPress>>`, `<<B1-Motion>>`, `<<ButtonRelease>>`）实现拖拽功能

### 3.3 旋转功能
- **旋转控制**：
  - 提供0-359度的滑块或输入框
  - 实现方式：使用Pillow的`Image.rotate()`方法，设置`expand=True`以确保旋转后的图片完整显示

### 3.4 技术实现类设计
- **WatermarkLayout类**：负责水印位置、旋转等布局相关功能
- **PreviewManager类**：负责实时预览窗口的管理和更新

## 4. 配置管理

### 4.1 水印模板管理
- **模板保存**：
  - 用户可以将当前所有水印设置（包括水印类型、内容、字体、颜色、位置、大小、透明度等参数）保存为一个命名模板
  - 实现方式：将设置参数序列化为JSON格式并保存到本地文件
- **模板加载**：
  - 用户可以从已保存的模板列表中选择并加载模板
  - 加载后自动应用模板中的所有设置
- **模板管理**：
  - 提供界面查看、重命名和删除已保存的模板
  - 实现方式：通过文件系统操作管理模板文件
- **自动加载**：
  - 程序启动时自动加载上一次关闭时的设置或默认模板
  - 实现方式：通过检查配置文件是否存在来决定加载行为

### 4.2 配置文件格式
- **存储格式**：JSON格式文件，易于解析和修改
- **文件位置**：存储在用户目录下的应用配置文件夹中
- **配置项示例**：
  ```json
  {
    "watermark_type": "text",
    "text_content": "Sample Watermark",
    "font": "Arial",
    "font_size": 24,
    "font_bold": true,
    "color": "#000000",
    "opacity": 80,
    "position": {"x": 100, "y": 100},
    "rotation": 0,
    "output_format": "jpg",
    "output_quality": 90,
    "scale_percentage": 100
  }
  ```

### 4.3 技术实现类设计
- **TemplateManager类**：负责模板的保存、加载、管理和删除
- **ConfigManager类**：负责应用配置的保存和加载，以及默认设置的管理
