# 水印文件应用需求规格说明

## 项目概述
开发一款Windows平台的水印文件应用，基于Python实现，支持多种图片格式的导入、处理和导出，并提供丰富的水印添加功能。

## 1. 文件处理

### 1.1 导入图片
- **单张导入**：支持单张图片拖拽或通过文件选择器导入。
- **批量导入**：支持批量导入，可一次性选择多张图片或直接导入整个文件夹。
- **图片列表显示**：在界面上显示已导入图片的列表（缩略图和文件名）。

### 1.2 支持格式
- **输入格式**：
  - 必须支持：JPEG (.jpg, .jpeg)、PNG (.png)
  - 强烈建议支持：BMP (.bmp)、TIFF (.tif, .tiff)
  - PNG格式处理：PNG格式必须支持透明通道。
- **输出格式**：
  - 用户可选择：JPEG (.jpg) 或 PNG (.png)

### 1.3 导出图片
- **输出文件夹选择**：用户可通过文件选择器选择导出图片的目标文件夹，通过路径比较默认禁止导出到原图片所在文件夹
- **文件命名规则**：
  - 保留原文件名：直接使用原始文件名
  - 添加自定义前缀：在原文件名前添加用户指定的前缀字符串
  - 添加自定义后缀：在原文件名（不含扩展名）后添加用户指定的后缀字符串
- **对于JPEG格式（可选）**：
  - 提供图片质量（压缩率）调节滑块（0-100）。
- **导出配置（可选）**：
  - 导出时允许用户调整图片尺寸（如按宽度、高度或百分比缩放）。

## 2. 水印类型

### 2.1 文本水印
- **内容输入**：用户可自定义输入任意文本。
- **字体设置（可选）**：可选择系统已安装的字体、字号、粗体、斜体。注意一定要支持中文，不能乱码。
- **颜色选择（可选）**：
  - 提供调色板组件让用户选择字体颜色
- **透明度调节（可选）**：可调节文本的透明度（0-100%）。
- **样式效果（可选）**：可添加阴影或描边效果，以增强在复杂背景下的可读性。

## 3. 水印布局与样式

### 3.1 实时预览
- **预览窗口**：所有对水印的调整都应在主预览窗口中实时显示效果。用户可以点击图片列表切换预览不同的图片。
- **实时更新**：当用户调整任何水印参数时，立即重新渲染预览图
- **图片切换**：用户点击图片列表中的缩略图时，切换主预览窗口显示的图片

### 3.2 位置控制
- **预设位置**：
  - 提供九宫格布局按钮组（左上、右上、左下、右下、上中、下中、左中、右中、中心）
- **手动拖拽**：
  - 用户可以在预览图上直接拖拽水印到任意位置

## 4. 配置管理

### 4.1 水印模板管理
- **模板保存**：
  - 用户可以将当前所有水印设置（包括水印类型、内容、字体、颜色、位置、大小、透明度等参数）保存为一个命名模板
- **模板加载**：
  - 用户可以从已保存的模板列表中选择并加载模板
  - 加载后自动应用模板中的所有设置
- **自动加载**：
  - 程序启动时自动加载上一次关闭时的设置或默认模板
